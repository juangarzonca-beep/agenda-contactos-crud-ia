# Agenda de Contactos Inteligente

## Descripción
Este proyecto es una aplicación web tipo CRUD (Crear, Leer, Actualizar, Eliminar) que permite gestionar una lista de contactos de forma dinámica. El diseño y la lógica fueron guiados y desarrollados en su totalidad mediante el uso de Inteligencia Artificial (asistente Cline en Visual Studio Code), aplicando buenas prácticas de estructuración y modularidad.

## Tecnologías Usadas
* **HTML5:** Estructura semántica de la aplicación.
* **CSS3 / Bootstrap 5:** Diseño moderno, limpio y completamente responsivo (adaptable a dispositivos móviles).
* **JavaScript Vanilla:** Lógica de programación para las funciones del CRUD (Crear, Leer, Actualizar, Eliminar).
* **LocalStorage:** Persistencia de datos local en el navegador del usuario para evitar la pérdida de información al recargar.

## Instrucciones para ejecutar el proyecto
1. Descargue los archivos de este repositorio o clone el proyecto.
2. Abra el archivo `index.html` en cualquier navegador web moderno (Google Chrome, Microsoft Edge, Brave, Mozilla Firefox).
3. Utilice el formulario para añadir contactos, editarlos, buscarlos o eliminarlos directamente.
